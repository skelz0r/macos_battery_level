# BatteryTime

Minimal macOS menu bar app displaying battery time remaining.

## Display

| State | Display |
|-------|---------|
| On battery | `3:45` |
| Charging | `⚡ 1:20` |
| Fully charged | `⚡` |
| Calculating | `...` |

## Build

```bash
./build.sh
```

## Run

```bash
open BatteryTime.app
```

## Install

Copy `BatteryTime.app` to `/Applications`.
